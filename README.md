# MakeMyAim Capital — Premier Frontier Venture Capital

A modern, high-conversion, luxury deep-tech Venture Capital firm website crafted with **React** and **Tailwind CSS**.

---

## ✨ Features & Capabilities

- 💎 **Ultra-Modern Silicon Valley & Swiss Luxury Aesthetic**
  - Deep obsidian dark palette (`#08090d`) with warm champagne gold accents (`#d4af37`, `#e6ca65`)
  - Glassmorphic frosted cards (`backdrop-blur-xl`, subtle micro-glow hover states)
  - Refined typography pairing: **Cormorant Garamond** luxury serif headlines with **Plus Jakarta Sans** and **JetBrains Mono**

- ⚡ **Interactive Founder Valuation & Runway Simulator**
  - Select funding round stage (Pre-Seed, Seed, Series A, Series B)
  - Interactive sliders for Target Raise ($500K - $30M), Dilution (10% - 28%), and Monthly Burn
  - Real-time calculation of Implied Pre-Money, Post-Money, Runway (months), and **MakeMyAim Fund IV Fit Score**
  - One-click "Pitch MakeMyAim with this Model" button that pre-populates the pitch wizard

- 🚀 **Multi-Step Founder Pitch Submission Wizard**
  - **Step 1:** Company profile & technical domain
  - **Step 2:** Capital dynamics & 1-sentence vision
  - **Step 3:** Secret sauce, technical moat, and pitch deck URL
  - **Step 4:** Instant simulated AI screening, partner assignment, reference ID generation, and celebratory confetti!

- 🔬 **Interactive Investment Thesis Explorer**
  - 5 Fund IV Pillars: *Frontier AI*, *Embodied Robotics*, *Quantum Hardware*, *Synthetic Longevity*, and *Clean Fusion*
  - Allocation breakdown, target check sizes ($3M - $25M), focus sub-sectors, and partner quotes
  - Direct 1-click filter button linking each thesis to relevant portfolio companies

- 💼 **Searchable & Filterable Portfolio Grid + Deep Dive Modal**
  - Filter by Domain (AI, Robotics, Quantum, Bio, Energy, Space)
  - Filter by Stage (Seed, Series A, Series B, Exits/Unicorns)
  - Real-time search bar across companies, founders, and co-investors (Sequoia, Founders Fund, a16z, etc.)
  - Interactive **Deep Dive Modal** featuring growth rates, ARR, valuation multiples, founder backgrounds, and milestones

- 👥 **General Partnership & Office Hours Portal**
  - Profiles for technical General Partners (ex-MIT, Stanford, Google DeepMind, Boston Dynamics, Tesla)
  - Interactive "Request 20-Min Office Hours" booking modal

- 🔒 **Institutional LP (Limited Partner) Vault**
  - Secure institutional login modal with instant "Preview Demo LP Vault"
  - Real-time fund performance displays (Fund I 4.82x TVPI, Fund II 3.38x TVPI, Fund III 34.8% Net IRR)
  - Downloadable quarterly reports and audited financial statements

- 📰 **Frontier Perspectives & Essays**
  - High-conviction whitepapers with interactive full-screen reader modal and 1-click share

- ❓ **FAQ & Global Hubs**
  - Accordion FAQ covering check sizes, 14-day speed to term sheet, and MakeMyAim Foundry portfolio platform
  - Global office addresses in San Francisco, New York, London, and Singapore

---

## 🛠️ Tech Stack

- **React 18**
- **Tailwind CSS 3**
- **Vite 6**
- **Lucide React** (icons)
- **Canvas-Confetti** (interactive submission effects)

---

## 🚀 Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```
